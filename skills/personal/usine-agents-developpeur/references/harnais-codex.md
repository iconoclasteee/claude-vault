# Harnais Codex

Appliquer ces points uniquement lorsque l’environnement Codex les prend en charge.

- Utiliser les sous-agents seulement si des tâches bornées et indépendantes
  améliorent matériellement la vitesse ou la qualité.
- Traiter la notification du sous-agent comme un signal de disponibilité ; vérifier
  séparément les processus externes qu’il a lancés.
- Utiliser un worktree distinct pour des écritures Git concurrentes, puis isoler
  aussi bases, ports, services, caches et ressources externes.
- Conserver les preuves importantes dans le dépôt ou dans un chemin persistant
  référencé par le rapport final.
- Pour un fichier synchronisé ou également édité par un humain, vérifier les
  verrous et risques propres au format, sauvegarder avant une transformation
  risquée et regrouper les écritures avant validation humaine.
