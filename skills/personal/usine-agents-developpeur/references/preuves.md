# Contrats de preuves

| Action | Preuve minimale |
|---|---|
| Modification de code | Diff inspecté et tests pertinents |
| Migration | Version enregistrée et structure ou données attendues |
| Seed ou import | Comptages et échantillons significatifs |
| Déploiement | Version réellement servie et chemin critique contrôlé |
| Correction UI | Aperçu ou capture et interaction représentative |
| Performance | Mesure avant/après dans des conditions comparables |
| Sécurité | Accès autorisé réussi et accès interdit refusé |

Un exit code nul, un message de succès ou un rapport d’agent est une information,
pas une preuve suffisante de l’état métier.
